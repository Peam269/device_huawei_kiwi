The Honor 5X (codenamed _"kiwi"_) is a midrange smartphone from Huawei.

It was announced in October 2015 and released in November 2015.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
SoC     | Snapdragon 616 (MSM8939v2)
CPU     | Octa-core (4x1.2 GHz Cortex-A53 & 4x1.5 GHz Cortex-A53)
GPU     | Adreno 405
Memory  | 2/3 GB RAM
Shipped Android Version | 5.1 (Lollipop)
Storage | 16 GB
Battery | Non-removable Li-Po 3000mAh battery
Display | IPS LCD, 5.5 inches, 1080 x 1920 pixels, 16:9 ratio (~401 ppi density)
Camera  | 13 MP, f/2.0, 28mm (wide), AF
Front Camera | 5 MP, f/2.4, 22mm (wide)
